# 能力宇宙 · 首轮素材风格样本

这是一组用于确认整体风格的原创 PNG 概念图。运行中的大屏保持第一版，尚未开始整体重构。这些图片不是可旋转的三维网格，也未绑定行走或工作动画。首轮六件之后按用户修订新增两件设备星球，共八件。

参考《戴森球计划》[官方 Steam 商店及截图](https://store.steampowered.com/app/1366540/Dyson_Sphere_Program/?l=schinese)中的科幻工业气质，提炼灰白外壳、石墨骨架、少量橙色功能标记和青蓝能源光；主体与结构为本项目原创概念。

[打开素材风格对照页](index.html)。所有 PNG 保留 RGBA 透明通道。

本机现有观察服务提供 [Tailscale 对照预览](http://scott-mac.tailfb4720.ts.net:4318/style-lab/universe-v1/index.html)，已从另一台 Tailnet 设备验证 HTTP 200。预览文件复制在被忽略的 `dist/style-lab/universe-v1/`；重新构建应用后，如需继续展示，可将本目录的 `index.html` 与八件 PNG 复制回该目录。源素材不受应用构建影响。

## 复用方向

素材后续按骨架、外壳、功能附件、身份徽章、状态灯拆分。二维图标、远景简化形态和近景三维模型共用同一视觉身份。建筑三维模型制作时，使用统一包围盒严格约束地块与高度；生成概念图不能替代几何尺寸校验。

独立视觉复核确认两款工坊外廓基本一致、三层材质具有家族感。正式制作时还要统一机器人与建筑的相机俯角，处理机器人少量透明边缘杂色，并统一星舰、工坊的柔和环境光晕与角色单体的输出标准。

## 生成记录

本轮使用内置 image_gen 工具。三个基础款先独立生成，三个变体分别引用对应基础款编辑，保留家族特征。完整最终提示词、输入引用和来源见 [manifest.json](manifest.json)。

设备星球修订的两件素材及完整提示词见 [planet-generation.json](planet-generation.json)。星舰的历史提示词保留生成当时的语义；当前用途以本文件和对照页为准。

## 设备星球与舰群规则

- 一台设备是一颗星球；当前 Mac 的主星地位来自用户明确指定，不声称由尚未完整接入的数据自动算出。
- 未来排序评价分别展示能力承载、核心职责与不可替代性、项目积累、真实协作依赖等依据。服务和技能计数需统一口径、采用递减增益，方法数不与服务重复加分；缺失维度显示待核验。
- 单核、双核、三核是可选布局。人工指定优先；未来系统可提供基于持续观察的中心候选建议。设备轨道表达空间组织，不暗示主从或必须经过中心调度。
- 设备身份、轨道与相位保持稳定；短时离线或目录读取失败影响状态标识，不立即缩小或更换中心。
- 星舰代表能力活动的抽样示意，远景可显示为点；显示密度与真实数量分开。巡航是示意动作，实际调用活动必须由执行记录另行确认。

本轮仅供风格评审；尚未将星舰等级、项目规模或角色忙闲映射为真实网络数据。
