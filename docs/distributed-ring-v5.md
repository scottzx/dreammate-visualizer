# 分布式设备圆环

所有设备共享一个倾斜圆环，围绕空中心顺时针公转。Mac 也在圆周上，无固定主星，球体仍沿用设备存储总容量对应的体积比例。

## 半径与间距

`N` 为完整快照内去重后的设备数，默认相邻设备的圆弧间距 `S = 16` 个世界单位：

```text
R = N × S / (2π)
Δθ = 2π / N
θᵢ(t) = θ₀ + i × Δθ + 0.02 × t
```

因此圆周长等于 `N × S`，每新增一台设备半径增加约 `2.5465`，数量翻倍则半径翻倍。13 台设备的半径约 `33.1042`。所有设备采用相同角速度，俯视为顺时针，约 314 秒完成一圈。轨道平面倾斜 8°；暂停和系统减少动态偏好会冻结展示时钟。

这里固定的是相邻球心沿圆周的弧长，直线距离为 `2R × sin(π/N)`，球体表面净距还取决于各设备的存储总容量。零设备不绘制圆环；单设备仍有有限半径。设备数来自完整快照，搜索、状态筛选和设备离线不会改变现有设备在圆环中的位置。实际设备加入或移除时重新均分圆周，保存已有设备的相对顺序；不为消失设备留空槽。返回设备恢复此前顺序。

## 对等互联

每对当前可见设备之间有一条无方向的淡色拓扑线，共 `N(N−1)/2` 条。选中设备时突出与它关联的连线，其余线变淡。连线随星球共转，以批量线段绘制，最多两次 draw call，不拦截星球点击；远景隐藏线段以保留光点可读性。

拓扑线表达对等关系，不产生事件、调用量或探活结果。实际连接可能受路由、访问控制与设备状态影响；已有明确因果证据的协作事件仍采用独立的虚线及事件详情。工具栏可一键切换互联与协作线显示。

## 导航与持久布局

总览围绕圆环中心，按圆环半径、最大星球包围尺度和视场角计算取景距离，并为标签及底部导航留白。在总览中新增设备会自动扩圈、调整镜头；手动旋转、缩放或聚焦后，刷新保留当前镜头，点击总览可重新适配。

选中星球可聚焦并跟随它公转；未选择时“聚焦星球”显示总览。进入基地和返回宇宙的操作保持可用。二维文字仍采用避让与细节层级，手机继续使用固定 16:9 舞台及横移条。

新的顺序登记使用 `dreammate.universe-layout.v2`，按实况/演示及来源隔离；不复用旧多轨道的空槽布局。

## 验证范围

几何和逻辑测试覆盖 0/1/2/3/6/13/24/100 台设备，核对闭环间距、半径增长、去重、相对顺序、顺时针运动、暂停和完整图连线；同时检查总览取景范围及容量体积比例回归。浏览器画面与实际交互记录见本地 `artifacts/distributed-ring-v5/`，本轮 55 项测试及生产构建通过，实况 13 台和隔离演示 13→14→15 台均完成浏览器验证；详细结果登记在验收记录中。实况设备状态和目录会随采样变化。
