# 宇宙沙盘科技风格迭代

用户反馈：原有地球仪式星球过于朴素，需要换一组星体，并增强动画、光效和科技感。

## 视觉目标

- 主星采用机械聚变结构，能辨认内部能量核心、分瓣装甲与轨道设施。
- 外围设备采用装甲计算星体，棱面、能量缝隙与主星形成区别；不再使用地球海陆图案。
- 空间具有多层光轨、扫描环、少量轨道粒子、星舰尾焰及明暗背景层次。能量流是装饰，不建立设备调用因果关系。
- 驾驶舱使用冷色边光、精细框线和深色半透明 HUD，文字与数值优先保持清晰。

## 约束和验收条件

16:9 固定舞台、竖屏横移、设备身份、三层浏览和实况/演示边界保持原有约定。真实在线、未知、离线仍以文字与来源证据区分，视觉发光不证明设备在线。

动画支持暂停及减少动态偏好；暂停后相机与标签仍持续正确绘制。模型仍为可下载和复用的 GLB，改造后的模型提供新版本地址以避免浏览器缓存旧素材。

对照图使用同样的 1280×720 窗口与正交相机，隐藏两侧 HUD、取消选择并暂停巡航。允许改变的变量为星体几何、材质、灯光、装饰效果与驾驶舱外观。前后画面保留在 `artifacts/tech-v3/`，不覆盖第二版记录。

## 本次实现与验证

星体仍沿用 `planet-hub` / `planet-peripheral` 的稳定身份；模型修订号为 `tech-orbs-v2`，GLB manifest 版本为 2。两类星体分别为 214,544 / 207,916 字节、15 / 20 个网格；构造器和建筑尺寸约定保留。

`UniverseEffects.tsx` 集中保存光效与配色：分段轨道环、扫描光扇、面向相机的柔光、轨道装饰粒子、星云、全域星空及舰船尾焰。独立时钟在暂停或减少动态偏好时停止推进，渲染本身继续保证镜头和标签同步。`cockpit-tech.css` 保存驾驶舱边光与界面外观。

42 项测试通过；生产构建及类型检查通过。星空采样修正了哈希相关和倾斜镜头裁切；星云渐变使用正序 smoothstep，避免未定义的着色器行为。

600×340 的同一区域截图比较：动画运行期间有 49,948 个像素发生可见变化；暂停期间为 0；减少动态偏好期间为 0，且页眉装饰动画也停止。比较不包含会变化的系统时间；动画检查期间只使用媒体偏好测试覆盖，已恢复。

390×844 竖屏的实际舞台为 1145.77×644.5，横移范围 756，按钮将 scrollLeft 从 378 移至 622.5。说明文字在手机界面移到独立的图例行，避免底部按钮遮挡。HUD 覆盖场景，不挤压比例。

总览、两类模型近景、左右 HUD、竖屏与竖屏 HUD 截图保存在 `artifacts/tech-v3/`；`capture-manifest.json` 记录实际源码与 GLB 的 SHA-256。浏览器未出现 error，Tailscale 地址下的新模型文件与 health 均为 HTTP 200。光效与装饰不新增网络数据，也不表明调用关系。

独立复审通过：总览、模型身份、光效、HUD、竖屏比例、暂停及减少动态效果均符合本轮约定。复审发现的手机说明遮挡已修正并重新截图。未测量不同物理设备的持续帧率。
