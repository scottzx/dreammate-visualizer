# 第一版实施计划 · 2026-10-22

依据根 README 已确认的 M1/M2 设计，采用 TypeScript、React、React Three Fiber / Three.js、Vite 与独立 Node.js 只读观察服务。npm 锁定依赖，公共协议仅从正式 npm exports 引用。

## 并行分工

- 数据接入智能体：Node 目录/健康/服务快照，明确 source/origin 的 ACP 读接口，分页与游标、去重、覆盖诊断，只读 API 和显式演示快照。
- 界面智能体：中文整体态势、范围指标、筛选搜索、设备/能力/工作单/事件下钻、来源覆盖与演示切换。
- 三维智能体：稳定身份布局、设备车间、服务工位、事件驱动活动和有证据链路、选择联动与视角控制。
- 主智能体：共享读模型与脚手架、依赖安装、真实接口核验、集成测试、浏览器验收与交付说明。

## 验收

1. 本机开发与生产构建均可启动，画面具备明确无数据与错误状态。
2. 真实/演示来源与指标完全隔离，未知/离线/过期/部分/无权限不伪装为零。
3. 设备位置按持久 ID 决定，刷新不随机移动；节点健康、服务健康和角色忙闲分开。
4. Job、Attempt、能力种类与实例分别统计，调用台账缺口可见。
5. ACP origin 必须来自显式配置；事件页有界排空，按 source/origin/job 范围保存游标和去重。
6. 只调用白名单读取接口，不建立执行控制连接，不修改相邻仓库。
7. 完成模型/适配器有价值的测试、TypeScript/生产构建和浏览器交互/视觉验证。

M3 历史与产物的完整下钻、M4 宿主只读流与完整回放仍依赖上游与明确授权范围，不作为本轮已完成承诺。
