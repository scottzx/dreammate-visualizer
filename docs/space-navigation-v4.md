# 三维星系导航

> 本文记录第四版的历史方案。当前设备统一排列为无中心的单圆环，公式及当前行为见 [分布式设备圆环](distributed-ring-v5.md)。

用户目标：设备应具有行星尺度，可以在三维空间中自由环绕；拉远时 Mac 核心也要变为微小光点。其他设备围绕指定 Mac 自转、公转。

## 生效设置

- 透视相机：45° 视场，观察距离 5–5000，默认相对中心偏移 `[0,48,76]`。水平旋转不设限，极角保留 0.005 弧度以避免极点奇异；可以从轨道下方观察。
- 所有星体共享公转时钟，Mac 位于 `[0,0.3,0]`；其他星体按稳定初始相位运行。内圈较快，倾角为 8°–20°。这属于展示运动，不是物理天文计算或实时任务数据。
- 投影半径小于 2.2px 时星体使用小光点；小于 3px 时隐藏名称卡片，即使主星已选中也不设最小图标尺寸。近景显示详细卡片和能力舰群。
- 导航提供拉远、拉近、聚焦星球、星系总览。聚焦可以跟随运动设备；平移会解除跟随。暂停与系统减少动态偏好冻结公转、自转和光效，仍可操作相机。
- 保留固定 16:9 沙盘和三层浏览。手机画布单指旋转，独立横移条移动宽沙盘视窗；HUD 覆盖当前可见窗口。
- 星空是 6500–9000 半径的世界空间球壳，星云背景适配透视视锥。原平面网格改为倾斜轨道环。模型仍使用 `tech-orbs-v2`，未重复修改 GLB。

## 验证

48 项测试通过，含新增 6 项公转/暂停/异常数值测试；TypeScript、生产构建通过。浏览器通过 Tailscale 地址验收，health 返回 200。

1280×720：默认相机距中心 89.89，Mac 投影半径 26.344px；拉远到 5000 后为 0.474px，所有星球标签隐藏，选中主星也保持该尺度。聚焦恢复距离 24.5、投影半径 96.655px。实际拖动镜头可到中心另一侧及轨道下方，拖动没有误触选择；滚轮令距离从 89.89 变为 95.11。来源定时刷新不复位相机。

暂停前外围设备坐标随共享时钟推进，核心坐标不动；暂停后两次读取时钟及坐标一致。系统减少动态偏好下也检查时钟和设备坐标停止，并在验收后恢复媒体及视口覆盖。物理手机双指手势和持续帧率未实机测量。

390×844：舞台 1145.77×644.5，比例 16:9；导航 y605–642，横移条 y653–691，图例 y706–745，目录 y755–788。右 HUD x38–382，位于可见窗口内。375×640：导航 y401–438，横移条 y449–487，图例 y508–547，目录 y557–590；修复短竖屏导航压到图例的问题。

独立代码复审发现隐藏证据连线仍会被 Three.js 射线命中，已在隐藏时跳过射线检测；隔离回归结果为隐藏 0 次命中、可见 1 次。未改变证据连线来源或制造调用关系。

最终截图及采集摘要位于本地忽略目录 `artifacts/space-v4/`。前后版本相机投影不同，`before.png` 是第三版正交相机基线，不能作为相同镜头的材质对比。实况来源随采样变化，截图中的在线数量不作为固定资产清单。

最终独立评审通过，28份源码/模型及10张截图摘要均匹配。标签避让后引导线较短属于后续可读性建议；实况快照没有事件，因此移动因果连线的浏览器交互未作验收。报告保存在 `artifacts/space-v4/review.md`。
