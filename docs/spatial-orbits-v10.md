# 立体轨道 v10

目标是让两层星系公转、球体自转和能力星环有自然的纵深。服务域名仍对应小太阳系的真实中心设备，DERP 保留为大公转中心，IP 隐藏继续生效。

每个星系的大轨道、每台设备的小轨道都有按稳定身份生成的独立倾角与升交点方向。倾角范围为 18–43°；同组设备在水平投影中保留均匀相位，三维距离随不同轨道朝向变化。轨道为倾斜椭圆，不再要求所有节点处于同一平面。能力星环也使用各自的倾斜方向、相位与转速。

球体绕按身份生成的斜轴旋转，自转轴倾角为 22–79°，转速与方向各异。公转、自转和能力星环继续共用可暂停的时钟；页面隐藏后的长帧不会造成突然跳跃。所有这些运动均为视觉示意。

各星系共用大公转角速度以保持相对间距；不同小星系可有不同的小公转速度，同组行星不会相互追赶。布局按椭圆的最小水平尺度保留星体与能力卫星的间隙，并按三维最大包络扩大星系间距与相机取景范围。轨迹线与星球位置使用相同函数，避免星球脱离星轨。

验证采用 91 项全量测试、生产构建与真实页面自检。回归包含独立轨道的空间体积、封闭轨迹和运动吻合、三维包络、2/5/20 台行星间距、身份稳定、暂停与恢复。截图和页面记录保存在 `artifacts/spatial-orbits-v10/`。本次为自检，不宣称独立评审；没有同条件的旧版截图，不作像素级前后比较。
