# 设备存储与球体比例

用户更正：球体反映设备存储总容量。原 RAM 采集与换算已移除，旧内存字段不会补入存储。

- 体积与总存储容量成正比，半径 `r = 1.8 × cbrt(storageBytes / 64 GB)`。存储翻倍，体积翻倍；半径乘以约 1.259921。
- 未取得有效存储总容量统一默认 128GB，并标注“默认”；取得真实容量后自动替换。保留此前同身份缓存与跨身份隔离规则。
- 本机 macOS 实际读取内置物理磁盘总容量 500277792768 字节，显示 500.3GB。采集不含外接盘，不重复统计 APFS 分区/卷，不受剩余空间或 RAM 变化影响。
- 来源契约使用 `NodeView.storage` 与 `metadata.hardware.storage_total_bytes` 等明确单位字段。界面、标签、图例、设备详情、模型图鉴和演示数据均改用存储口径。数据来源与平台边界见 [来源配置](data-sources.md#设备存储总容量与星球体积)。

本轮 56 项测试、TypeScript 与生产构建通过。新增/调整检查覆盖 RAM 数据不能冒充存储、GB/GiB 换算、TB 显示、128GB 默认、采集优先级、磁盘去重、APFS 避重和读取失败后的同身份缓存。实际页面验收与产物保存在 `artifacts/storage-v6/`，不把旧 RAM 截图作为本轮证据。

生产浏览器与 API 均确认 Mac 存储总容量为 500277792768 字节、世界半径约 3.572314；其余 12 台未上报设备按默认 128GB 半径约 2.267858 显示。标签、详情及图例使用存储口径，旧 memory 字段不再返回。Tailscale health 200，浏览器无 error，实况动态总览已恢复。本轮为非独立自检。
