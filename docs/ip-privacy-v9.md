# IP 隐私 v9

观察后端在所有 `/api/snapshot` 响应中统一隐藏 IP，覆盖真实、演示、强制刷新与其他查询参数。浏览器只接收脱敏快照；`privacy.ipAddresses` 固定为 `hidden`，响应禁止缓存。

处理覆盖节点、来源、诊断、证据链接、网卡、子网和 DERP 字段，包括 IPv4、IPv6、带端口的 URL 和 URL 编码的地址。含地址的实体标识与引用用进程内稳定的 HMAC 标识替换，保留唯一性和关联，不合并成一个占位节点。采集侧保留真实地址以继续读取现有来源。

服务域名继续作为小太阳系的入口标识。通过 IP 打开的页面以“当前服务”命名；中心设备通过快照的服务节点身份绑定。详情、图例、设备目录与星球标签显示设备名或地址已隐藏提示；网卡保留名称和 MAC，隐藏 IP 与子网。

回归覆盖地址格式与编码、域名保留、稳定引用、原快照不变，以及 HTTP 各快照入口不能关闭脱敏。浏览器验证记录和当前脱敏截图保存在 `artifacts/ip-privacy-v9/`。
