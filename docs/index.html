DESIGN APPROACH · 设计思路

四步，把能力接进网络

从一台设备上线，到一次调用被记录，每一步都留下可查询的事实。

  1. 01设备接入

    每台设备运行一个节点，报出身份、服务与健康状态。

  2. 02声明能力

    服务描述自己能做什么、通过什么方式访问。

  3. 03发现与调用

    Agent 检索能力、检查契约，按可用路径调用。

  4. 04留下轨迹

    会话与执行记录留在网络里，过程可以回看。

同一个能力可以声明多种访问方式。调用方按顺序选择，不需要知道底层用的是哪一种。
