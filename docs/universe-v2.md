# 能力宇宙驾驶舱 · 第二版

## 本轮目标与素材

在已确认的科幻工业风格上制作可复用真实三维模型，并实装到宇宙沙盘。PNG 概念图保存在 `assets/concepts/universe-v1/`，仅作美术方向参考；场景使用可旋转的几何模型与导出的 GLB，不能用图像平面假扮三维模型。

设备是一颗星球，当前 Mac 是用户指定的视觉主星。外围设备围绕中心区排布；轨道表达空间组织，不代表必须经过主星调度。舰群表现服务、智能体入口等能力规模的抽样示意，巡航不等于实时执行。真实执行仅依据已有事件记录。

## 三层浏览

1. 宇宙总览：设备星球、稳定轨道、能力示意舰群；选择设备后显示指标与详情 HUD。
2. 星球基地：平面地图，服务工厂、技能学院、智能体驻地与项目工坊。建筑统一占地与总高度，按规模区间变化材质、设备与附件。
3. 建筑观察：近距离旋转观察独立模型，HUD 展示服务方法、技能目录或项目参与构成；演示项目用人物呈现会话宿主组成。当前没有可行走的室内空间或执行控制。宿主会话占比不等于智能体贡献质量。

项目、独立会话与完整角色身份未接入真实采集，本轮实况保持明确的待接入状态；演示项目与占比为独立示例，不写入实况。跨设备项目在演示中保持统一身份，不重复算为不同项目。

## 驾驶舱与固定沙盘

主舞台始终保持 16:9。横屏以沙盘为主体，左右 HUD 叠加显示、可收起；HUD 不挤压三维场景比例。竖屏以可用高度确定沙盘高度，横向宽度按 16:9 延伸，用户左右移动查看。禁止以窄屏宽度自动缩小整张沙盘、字号或镜头。

布局与选中对象按稳定身份保存；搜索与筛选不重新排列设备。未知、离线、过期、部分覆盖与可用状态继续区分。主星来自用户指定，承载量只提供可解释的视觉规模参考，不宣称完成全网重要性排序。

## 生成与验证

`npm run assets:build` 从可复用模型构造器导出 `public/models/universe-v1/`。`npm test` 覆盖模型尺寸、展示口径、稳定布局与观察后端；`npm run build` 检查类型与生产包。浏览器验收需要分别检查横屏总览、左右 HUD、基地与建筑观察、竖屏横移及窗口旋转后比例。

验收截图必须来自同一组代码和 GLB；暂停舰群后检查可读性。建筑包围盒用实际几何验证，不能只靠 PNG 或截图判断尺寸。WebGL 不可用时应展示可点击的设备/建筑替代界面。

本轮不增加派单、执行、取消或重试控制，不修改 Node 或 ACP 来源。继续使用已有 launchd 托管和 Tailscale 双地址访问。
