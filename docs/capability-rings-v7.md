# 能力星环、Skill 星点与项目存储

本轮沿用戴森球和设备存储体积比例，保留分布式设备圆环与已有导航。用户已确认：**一个 Skill 包一个星点；项目统计存储空间，不统计 RAM**。

## 图形含义

- 细星环为设备的能力轨道；每个可见服务部署对应一颗卫星。点击卫星打开该服务的真实方法目录。全部可见服务参与绘制，取消旧舰群的抽样数量。
- 每个非空 Skill ID 对应一个星点。同节点多服务申报相同 ID 只画一个点，同名不同 ID 保留。目录部分覆盖时标记“部分”；缓存条目保留缓存含义，不生成额外装饰粒子冒充技能。位置由节点与 Skill ID 确定，刷新不随机洗牌。
- 球面经向色块的面积份额为 `该类别已测目录存储 / 已采集设备总存储`。蓝色表示业务智能体，绿色表示感知能力，紫灰表示其他已测项目。灰色保留未探查、未归属、其他文件和空闲空间，不等于空闲空间。
- 没有项目测量、读取失败、容量冲突或设备只有默认128G时，不绘制项目占比。已测字节仍可单独查看；默认容量只用于显示设备大小。
- 星环的运动是展示效果，卫星不代表正在执行的智能体，目录存在不证明项目正在运行。

## 项目数据

新增 `localProjects` 显式目录配置，与现有 `localNodeId` 绑定。观察端只测量这一个已匹配 Node 的目录，不把本机大小分配给远程设备。

```json
{
  "localNodeId": "your-local-node-native-id",
  "localProjects": [
    { "id": "agent", "name": "智能体项目", "path": "/absolute/path/to/project", "category": "business-agent" },
    { "id": "perception", "name": "感知项目", "path": "/absolute/path/to/perception", "category": "perception" }
  ]
}
```

只读执行 `du -skx`，取得已分配磁盘块字节数，包含依赖、构建、隐藏文件；不读取文件内容。每60秒更新，单次测量限时6秒，并限制并发。缺失、无权限、超时保留 `null`，不采用失败命令的部分结果。规范化真实路径，重复、别名或父子重叠目录拒绝计入；不同文件系统不与观察机容量混算。APFS 克隆及跨目录硬链接可能共享块，因此统计不是可回收物理空间。

本机当前配置两个目录：1ACP 智能体协作、端侧语音感知。它们是明确范围的局部统计，外置模型缓存、运行时数据库及其他项目未自动纳入。远程设备尚无项目大小来源，显示灰色。项目列表接入某台设备，不意味着其他设备的项目数为0。会话统计、活动归属和交付产物仍按原接口覆盖情况处理。

## 验证

测试覆盖服务完整枚举、Skill ID 去重、缓存条目优先级、跨设备项目大小隔离、真实容量分母、默认128G不参与比例、读数冲突、未知与0区别、目录身份绑定、缓存更新、重复/父子/别名路径排重、失败读数和子符号链接不遍历。浏览器检查实况卫星点击、Skill 数量、项目占比、未知灰色和演示色块，截图与记录保存在 `artifacts/capability-rings-v7/`。截图为本次运行的自检记录，未宣称独立评审。
